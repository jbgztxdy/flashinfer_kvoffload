# Host CTA balancing experiments

GPU 2: A100-SXM4-40GB, 108 SMs. Host NUMA node 1. BF16, one query, 64 heads, latent 512 + RoPE 64, page size 1, top-k 2048, random placement.

Each candidate is paired with the frozen segmented binary using identical inputs and physical KV allocations. Graphs contain 100 serialized cycles; eight index sets are rotated. GPU times include attention and, for Memcpy, an actual H2D transfer every cycle. CPU packing, top-k, planning, and index updates are excluded. Timings are in us. Positive paired changes mean slower execution.

Phase traces use coarse globaltimer samples and are excluded from latency comparisons. The early host_read_end_us field includes segmented QK; the corrected field is host_qk_ready_us. Neither is a pure PCIe transfer measurement.

## Default policy

Keep 16 local, 32 Host, and 32 active merge CTAs. At least 410 Host rows enable ready-first merging in batches of 16; lower counts use bulk merging. The count is published by local split zero and read after acquiring its ready flag. Experimental allocations and mixed workers remain opt-in.
