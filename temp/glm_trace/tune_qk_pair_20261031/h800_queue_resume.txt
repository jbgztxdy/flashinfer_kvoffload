# rtx 工作目录约定

本文件适用于本目录及其所有子目录。

## 项目记忆

- 项目记忆统一存放在本目录的 `MEMORY.md`（`/WORK/PUBLIC/luyouy_work/rtx/MEMORY.md`）。
- 开始本目录下的工作前，先阅读 `MEMORY.md`；后续将需要跨会话保留的用户偏好、关键决策、已验证结论和待办更新到该文件。
- 不将项目记忆写入用户主目录或 `~/WORK` 根目录，也不在这些位置创建记忆副本。
- 记忆保持简洁，注明重要结论的日期和验证依据；更新或删除过时内容，避免重复堆积会话记录。当前用户指令优先于历史记忆。

## GPU 任务

- 所有 GPU 任务必须通过 Slurm 调度，遵守集群的 Slurm 使用规范。
- 批处理任务使用 `sbatch` 提交；交互式任务通过 `salloc` / `srun` 申请并使用资源。仅在 Slurm 分配的 GPU 资源内运行 GPU 程序，禁止绕过调度直接占用 GPU 或在登录节点运行 GPU 任务。
- 按实际需求声明 GPU、CPU、内存和运行时限；分区、账户、QoS 及 GPU 申请方式以集群配置为准，不猜测配置。
- 提交前检查任务的工作目录、环境和日志路径，确保符合下述存储要求。

## 文件存储

- `~/WORK` 是分布式文件系统，所有文件必须存储在该目录下。本目录是 rtx 的工作目录，相关文件默认存储在本目录及其子目录中。
- 代码、数据集、模型权重、检查点、实验结果、日志、下载文件、环境、缓存和临时文件均须遵守上述要求。
- 不将文件写入 `~/WORK` 之外的路径，例如节点本地磁盘、`/tmp`、`/var/tmp` 或主目录中的默认缓存目录。
- 运行工具或任务前，将其输出、缓存和临时目录显式配置到 `~/WORK` 下；必要时设置 `TMPDIR`、`XDG_CACHE_HOME` 以及工具专用的缓存变量。
- Slurm 脚本中的工作目录和标准输出、标准错误日志路径也必须位于 `~/WORK` 下；运行前创建所需目录，确保计算节点可访问。

## Slurm 查询与提交

- 查看分区和 GPU：`sinfo -o '%P %a %l %D %G'`
- 查看自己的任务：`squeue -u "$USER"`
- 查看账户、分区和 QoS：`sacctmgr show assoc where user="$USER"`
- 示例（按实际账户、QoS 和分区调整）：

  ```bash
  mkdir -p "$HOME/WORK/rtx/logs"
  sbatch --partition=h01 --gres=gpu:h800:1 --cpus-per-task=4 --mem=32G --time=00:10:00 \
    --output="$HOME/WORK/rtx/logs/%x-%j.out" --wrap='cd "$HOME/WORK/rtx" && nvidia-smi'
  ```

- `S:0-1` 表示 GPU 关联的 CPU socket 编号为 0–1，不代表 GPU 共享配置。
- 上述资源清单可直接用于选择分区，无需每次重复全量查询；排队、提交失败或需要确认空闲资源时再查询实时状态。
- CUDA 编译器：`/usr/local/cuda/bin/nvcc`，当前版本 12.4。
