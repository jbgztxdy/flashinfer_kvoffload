# 模拟远端链路：带宽与延迟（A100，NVLink 远端 = GPU1 HBM，跨 decode 稳态，开 LRU，每请求 4096 槽，µs）

由 `temp/sim_link/report.py` 从同目录的 JSON 生成。两种理论下限：
- **下限 a** = max(纯本地计算, 本步去重后的未命中字节 ÷ 模拟链路带宽)：本文 kernel 在这条链路上能达到的极限。
- **下限 b** = 纯本地计算：所有选中行都在本地 HBM、零传输时原生 kernel 的耗时（正常构建、无模拟钩子），即 KV 全放 HBM 时的性能。
- 「不限速」行的传输下限按 NVLink 实测峰值 262 GB/s 计。所有本文与朴素方法都在同一个模拟构建下测（含钩子开销），下限 b 在正常构建下测，对本文偏保守。
