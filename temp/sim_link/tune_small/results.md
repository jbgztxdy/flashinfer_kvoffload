# A100 单 query 合并：同参数对照

基线为 aeca4403 的 kernel（与 614655f1 相同）。每格固定 f16/h64、4096 槽/请求，7 pass，稳态取后一半步的逐步中位数平均。正值为耗时下降，负值为回退。本表采用候选后重跑的基线；另有基线先跑的数据和未采用候选，均保留。

代理 trace 为 64K/32 连续位置；glm64k 为真实 GLM 的 64K/1024 混合角色位置，不是完整 assistant 窗口。MTP8 的 128 请求为 1024 行，属于大 batch。

下限 b 采用此前相同维度正常构建全 HBM attention 的最快样本；a = 逐步 max(b, 去重未命中字节/带宽) 的稳态平均。模拟链路用设置带宽，真实链路用当次 DMA/SM gather 较快值。固定延迟未计入 a；不截断比值。
