# LRU 与小 batch 分块：本机 A100 前后对照

基线为 d92e7e83；同一 trace、每请求 4096 槽，前后各格使用完全相同的 planner 参数。本轮不混入上一轮调参收益。稳态为后一半步的逐步中位数平均，单位 µs。

代理 trace 为 64K 上下文、32 连续位置；GLM8K 为真实 top-k 的 256 连续位置接入。每份数据保留选中页的逐步参考校验、未命中页数和计时 pass 样本。

下限 b 为本轮正常构建纯 HBM attention 的最快样本；下限 a 为逐步 max(b, 去重后未命中字节/链路带宽) 的稳态平均。模拟链路采用校准目标带宽；Host 取当次 DMA/SM gather 实测较快值。比值不截断。
